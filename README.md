## `evExpress` - Evaluate text string as an expression in SAS

---

The `evExpress` package is a bunch of macros and functions
design to help evaluate SAS expressions that are provided
in a form of a text string.

SHA256 digest for the latest version of `evExpress`: F*9C8F32B00FD7FFCC184B79D46ECFB523D85EAF54DEFE375798743F28D8FA3677
